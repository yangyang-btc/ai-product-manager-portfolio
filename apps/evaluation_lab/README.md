# AI Agent Evaluation Lab

Run locally:

```bash
EVALUATION_LAB_MODE=local uv run python -m streamlit run apps/evaluation_lab/app.py
```

The online lab executes deterministic quality-project evaluation. Contract review and enterprise
RAG use versioned read-only reports generated by their local runtimes. Handoff credentials are
read from the URL fragment, removed from browser history, redeemed once, and stored only in the
current Streamlit session.

Bundle upload is available only when `EVALUATION_LAB_MODE=local`. Public deployments default to
read-only mode and do not accept visitor-generated bundles.
